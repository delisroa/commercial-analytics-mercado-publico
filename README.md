# Commercial Analytics — Mercado Público

Proyecto de análisis comercial enfocado en desempeño de ventas, KPIs, rentabilidad y oportunidades dentro de Mercado Público.

## Objetivo

Analizar información comercial para identificar patrones, oportunidades y factores asociados al desempeño de ventas y adjudicaciones.

## Contexto de negocio

El proyecto utiliza datos asociados a procesos comerciales de Mercado Público, con foco en métricas relevantes para la gestión de ventas y toma de decisiones.

## Herramientas

- Python
- Pandas
- NumPy
- Tableau
- Excel
- SQL

## Análisis incluidos

- Limpieza y preparación de datos
- Análisis exploratorio
- KPIs comerciales
- Análisis de ventas y adjudicaciones
- Rentabilidad y utilidad
- Análisis por producto y categoría
- Tendencia temporal
- Visualizaciones
- Modelo predictivo
